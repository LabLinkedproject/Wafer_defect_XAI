# 다이·웨이퍼 판정 재정의

2026-11-16 사용자 지시. 기준값은 사용자가 권장안으로 위임했다.

## 왜
- 다이 안의 결함 개수를 세는 세밀한 검출은 개수 오차가 판정 오류로 이어진다. 패턴이나 복합 패턴이 나오면 결과 출력도 흔든다.
- 결함은 다이 하나에 갇히지 않는다. 스크래치 하나가 여러 다이에 걸칠 수 있다(18:20 스크래치 시험 스캔).

## 다이 판정 (정상 / 불량 / 재검사)
| 판정 | 조건 |
|---|---|
| 정상 | 결함 없음 |
| 불량 | 결함이 다이 중심부에 닿음, 또는 다이 안 결함 면적이 다이의 5 % 이상 |
| 재검사 | 결함이 다이 가장자리 띠 안에만 있고 면적이 5 % 미만. 회생 가능할 수 있어 사람이 육안으로 정상·불량을 정한다 |

- 중심부: 다이 가장자리 4 mm 띠를 뺀 안쪽 24×24 mm.
- 결함 면적은 다이 안에 들어온 부분만 센다.

## 결함은 웨이퍼 단위
- 다이별 검출 조각을 웨이퍼 좌표에 다시 놓는다. 그런 다음 다이 경계(스크라이브)와 검사 제외 영역만 사이에 둔 조각은 하나로 잇는다.
- 결함 종류(particle·scratch·stain)는 이어 붙인 전체 모양으로 정한다.
- 판정은 결함이 걸친 다이마다 따로 낸다.
- 결함 개수는 세지 않는다. 다이마다 어떤 종류가 있는지만 남긴다.

## 웨이퍼 판정 (양품 / 불량 / 재검사)
1. 불량: 패턴 모델이 패턴을 판정했거나, 불량 다이가 검사 다이의 10 % 이상.
2. 재검사: 1이 아니면서, 재검사 다이가 있거나 모델 점수가 판정선 근처(의심)일 때. 사람이 최종 판단한다(Z플랜).
3. 양품: 그 밖.

## 패턴 모델 입력
- 불량 다이만 넣는다. 재검사 다이는 정상으로 취급한다.
- 사람이 재검사 다이를 불량으로 확정하면 그때 입력에 들어간다.
- 정의 밖의 변칙 상황은 모델 추론(XAI)에 맡기고, 그래도 애매하면 사람이 판단한다.

## 화면
- 다이 판정 맵 범례: 정상 / 불량 / 재검사.
- 다이 상세: 판정과 이유(중심부 침범 / 면적 / 엣지만)를 보이고, 정상·불량 확정 버튼(사람 판단)을 둔다.
- 결함 개수 표시(칸 안 숫자, 밀도 보기, "n건")는 없앤다. 종류 비율은 다이 수로 보인다.
- 판정 요약에 웨이퍼 판정을 보인다.

## 이번에 하지 않는 것
- 정답 기록에 다이 판정(불량/재검사)을 적는 기능. 지금 정답 기록은 결함 다이와 종류만 비교하고, 개수 비교는 뺀다.
- 기준값(4 mm, 5 %, 10 %) 보정. 실물 스캔이 쌓이면 다시 본다.
