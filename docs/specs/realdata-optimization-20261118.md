## 고친 것과 근거

### 1. 다이 격자를 갠트리 기준으로 (wafer_stitch.gantry_grid)
- 증상: 격자 측정 실패 4장(분석 불가), 잰 피치가 3~8 % 어긋난 4장(다이 칸이 가장자리로 갈수록 밀림).
- 원인: 격자 측정은 반 칸 넘게 이어진 선만 쓰는데, 격자선(다이 경계)이 사진 가장자리 = 겹침 가중치 낮은 제외 구역에 놓인다.
  잰 피치는 카메라 축척 추정이 틀리면 같이 틀린다.
- 고침: 사진은 다이마다 갠트리로 32 mm 씩 옮겨 찍으므로 칸 간격은 갠트리 이동량 그대로다. 피치는 웨이퍼 원(갠트리)에서,
  기울기만 잰 값을 쓴다. 사진에서 찾은 원이 규격(135 mm)과 5 % 넘게 다르면 버린다(14:29 스테인 고리·15:36 전면 스테인을 원으로 잡음).
  카메라 기준값은 그 스캔보다 먼저 찍은 스캔에서만(나중에 다시 합성해도 같은 결과).
- 기존 맵: `tools/regrid_gantry.py` 로 격자 정보만 다시 씀(영상 그대로). 원이 틀린 14:29·15:36 은 다시 합성.
- "위치 자동 보정 금지 — 원점은 사용자가 맞춘 대로"와 같은 방향이다: 사진이 아니라 사용자가 맞춘 원점과 갠트리 이동량을 믿는다.

### 2. 둘레 다이 검사 (wafer_detect.crop_dies)
- 증상: 다이 30·42 가 15장 중 7장에서 검사 밖 → 그 자리 결함을 늘 놓침(사용자 메모 "42번 다이 검출이 매우 잘 안 됨").
- 원인: 다이들의 보통 촬영 비율의 85 % 미만이면 뺐다. 둘레 다이는 이웃 사진이 덮어 주는 몫이 없어 66~68 % 로 문턱(68~69 %) 바로 아래.
- 고침: 다이 면적의 절반 이상 찍혔으면 보이는 부분이라도 검사한다.

### 3. 패턴 근거 검토 (adc/geometry.py) — 모델 밖에서 스스로 따지기
- 증상: 학습 모델이 둘레 입자 고리를 Scratch 로 읽음(17:13·14:16, 검출된 스크래치 0 개), Edge-Ring 은 한 번도 못 맞힘,
  다이 격자에 안 맞는 도넛을 Local 로 읽음(16:23), 복합 패턴에서 Local 대신 Random(16:02).
- 원인: 모델은 다이 격자(8×8) 지도만 본다. 결함의 실제 모양·위치는 모른다.
- 고침: 검출된 결함 위치로 다시 따진다.
  - 결함 위치에 원을 맞춰 속이 빈 고리(둘레 270° 이상)를 찾는다 → 웨이퍼 둘레면 Edge-Ring(엣지 다이 60 % 이상 불량, 안쪽은 그 절반 이하), 아니면 Donut.
  - 검사 다이 80 % 이상 불량이면 Near-full, 3 다이 넘게 잇는 스크래치면 Scratch.
  - 구조 근거가 있을 때 그것으로 설명되지 않는 불량 다이를 덩어리(Center·Edge-Loc·Local)와 흩어짐(Random)으로 가른다.
  - 근거와 맞지 않는 모델 라벨은 이유와 함께 뺀다(스크래치 없는 Scratch, 고리가 둘레를 다 덮었는데 Edge-Loc, 다른 패턴으로 다 설명되는데 Local·Random).
  - 근거와 기각 이유는 판단 기록(XAI)과 패턴 막대('배치'·'기각')에 보인다. 모델 점수는 바꾸지 않는다.

### 4. 다이 밝기 자기 점검 (wafer_detect.die_uniformity)
- 증상: 15:36 전면 스테인 → 결함 0 개, 양품. 15:46 도 결함 7 개뿐.
- 원인: 검출은 같은 웨이퍼 다이끼리(중앙값 기준) 비교한다. 대부분 다이가 같은 오염이면 기준도 더러워진다.
  깨끗한 기준 웨이퍼와 비교(이미 있는 기능)도 시험했지만 스테인은 4~12 개만 잡고 정상 웨이퍼에 오검출이 10~17 다이 생겨 쓰지 않는다.
- 고침: 다이 밝기(안쪽 중앙값) 변동계수가 0.25 이상이면 넓은 오염 의심 → 양품을 재검사로 올리고 어두운 다이를 알린다.
  실측: 전면 스테인 0.29·0.56, 그 밖 22장 ≤ 0.22. 사람에게 넘기는 쪽으로만 쓴다(불량으로 단정하지 않음).

### 5. 붙은 스크래치 가르기 (wafer_detect._line_made)
- 증상: 엇갈린 두 스크래치(11-17 15:05)·스크래치 군집(16:51)이 합쳐져 평균 폭이 3.3 mm 를 넘어 스테인으로 나옴.
- 고침: 번짐이 대부분이 아니고 평균 폭 4.5 mm 이하인 결함이 20 mm 넘는 곧고 가는 선분 몇 개(최대 8)로 80 % 설명되면 스크래치.
  넓은 스크래치는 양쪽 가장자리만 두 줄로 잡혀 선분이 많이 든다. 굵은 붓질·휘어진 스테인 고리·덩어리는 해당하지 않는다(시험 포함).
  가는 결이 여러 줄인 스테인 띠(14:29, 평균 폭 6.2 mm)는 폭 상한으로 막는다.
